JpegImageReader

  • ImageReader
ImageReader for JPEG images, backed by jpegli.

A JPEG file holds exactly one image, so #getNumImages(boolean) always answers 1 and #read(int, ImageReadParam) decodes that one. The pixels arrive as a BufferedImage#TYPE_4BYTE_ABGR image, whose banks are the very A, B, G, R layout the jpegli shim fills in, and are then converted to the requested type when the caller asked for something else.

A greyscale file is upsampled to the same three channel layout rather than handed back as BufferedImage#TYPE_BYTE_GRAY, so that a caller sees one shape for every JPEG. The alpha channel is fully opaque either way, because a JPEG cannot carry a real one.

Of the ImageReadParam settings, the source region, the source sub sampling factors and the destination are honoured, by StillImageRead rather than here. Band selection and the sub sampling offsets are not; the reader produces all four channels and starts every sub sampling block at its own top left corner.

See JpegliCodec for how the native library is located. When it is missing, this reader is not offered to ImageIO at all, which is what leaves the JDK's own JPEG reader in place rather than failing every read.

Instances are stateful and, as mandated by ImageReader, not thread safe.
