Registers SvgImageReader with ImageIO.

Decoding needs the Apache Batik library on the classpath. To keep ImageIO usable when that library is absent, #canDecodeInput(Object) answers false in that case, which makes ImageIO.read() fall through to the other providers instead of failing hard.

VERSIONString

Version of this service provider implementation.

SvgImageReaderSpi()

ImageIO builds the provider reflectively, so it needs a public no-argument constructor; the accepted input types are copied in here rather than assigned directly, so that a caller editing the inherited field cannot reach the shared constant through it.
