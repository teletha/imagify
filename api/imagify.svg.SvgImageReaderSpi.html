Registers SvgImageReader with ImageIO.

Decoding needs the Apache Batik library on the classpath. To keep ImageIO usable when that library is absent, #canDecodeInput(Object) answers false in that case, which makes ImageIO.read() fall through to the other providers instead of failing hard.
