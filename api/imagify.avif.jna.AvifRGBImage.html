AvifRGBImage

  • com.sun.jna.Structure

A block of interleaved RGB(A) pixels handed to, or received from, libavif: avifRGBImage.

widthint

Image width in pixels, must match the associated AvifImage.

heightint

Image height in pixels, must match the associated AvifImage.

depthint

Bits per channel; 8, 10, 12 or 16.

formatint

An AVIF_RGB_FORMAT_* value.

chromaUpsamplingint

An AVIF_CHROMA_UPSAMPLING_* value.

chromaDownsamplingint

An AVIF_CHROMA_DOWNSAMPLING_* value.

avoidLibYUVint

An avifBool; when set, libyuv is bypassed.

ignoreAlphaint

An avifBool; when set, alpha bearing formats are treated as opaque.

alphaPremultipliedint

An avifBool; when set, the colours are already premultiplied.

isFloatint

An avifBool; when set, 16 bit samples are half floats.

maxThreadsint

Number of threads used for YUV to RGB conversion; 0 or less means one.

pixelscom.sun.jna.Pointer

The pixel buffer.

rowBytesint

Row stride in bytes.
