AvifAnimationDecoder

  • AutoCloseable

Walks the frames of an AVIF file, decoding them one at a time.

A file holds either one still image or an image sequence, and this class treats both the same way: a still is a sequence of one. #frameCount() is answered from the container headers alone, so asking how many frames there are never decodes a pixel, and #frame(int) decodes only the frame asked for rather than the whole file.

The decoder holds native memory, so it is meant to be closed, ideally with try with resources: 


 try (AvifAnimationDecoder decoder = AvifAnimationDecoder.open(bytes)) {
     for (int i = 0; i < decoder.frameCount(); i++) {
         BufferedImage frame = decoder.frame(i);
         // ...
     }
 }

Instances are not thread safe.

frame(intindex)BufferedImage

intindex

the frame to decode

AvifException

Decodes one frame as a BufferedImage#TYPE_4BYTE_ABGR image, whose banks are the very A, B, G, R layout libavif fills in for AVIF_RGB_FORMAT_ABGR.

Frames of an animation are returned at the size they are stored at, which for a sequence that updates only part of the canvas can be smaller than #info(). The alpha channel is fully opaque when the file carries no alpha.
