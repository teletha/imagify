AvifImage

  • com.sun.jna.Structure
  • ByReference

A decoded or to be encoded AVIF image: avifImage.

All C enumerations are mapped to int, which is how libavif declares them (typedef enum { ... } avifPixelFormat; and friends).

widthint

Image width in pixels.

heightint

Image height in pixels.

depthint

Bits per channel; all planes share this depth.

yuvFormatint

An AVIF_PIXEL_FORMAT_* value.

yuvRangeint

An AVIF_RANGE_* value.

yuvChromaSamplePositionint

An AVIF_CHROMA_SAMPLE_POSITION_* value.

yuvPlanescom.sun.jna.Pointer

The three YUV planes.

yuvRowBytesint

Row stride of each YUV plane in bytes.

imageOwnsYUVPlanesint

An avifBool telling whether #yuvPlanes has to be freed by us.

alphaPlanecom.sun.jna.Pointer

The alpha plane, or null.

alphaRowBytesint

Row stride of the alpha plane in bytes.

imageOwnsAlphaPlaneint

An avifBool telling whether #alphaPlane has to be freed by us.

alphaPremultipliedint

An avifBool telling whether the alpha channel is already premultiplied.

iccAvifRWData

Embedded ICC profile, if any.

colorPrimariesint

An AVIF_COLOR_PRIMARIES_* value.

transferCharacteristicsint

An AVIF_TRANSFER_CHARACTERISTICS_* value.

matrixCoefficientsint

An AVIF_MATRIX_COEFFICIENTS_* value.

clliContentLightLevelInformationBox

Content light level information.

transformFlagsint

An AVIF_TRANSFORM_* bit set.

paspPixelAspectRatioBox

Pixel aspect ratio.

clapCleanApertureBox

Clean aperture (cropping) rectangle.

irotImageRotation

Rotation transform.

imirImageMirror

Mirror transform.

exifAvifRWData

Embedded Exif payload, if any.

xmpAvifRWData

Embedded XMP payload, if any.
