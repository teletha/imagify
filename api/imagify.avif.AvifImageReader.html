imagify.avif

AvifImageReader

  • ImageReader
ImageReader for AVIF images, backed by libavif.

An AVIF file holds a single still image, so this reader always reports exactly one image. The pixels are decoded into a BufferedImage#TYPE_4BYTE_ABGR image, whose banks are the very A, B, G, R layout libavif fills in for AVIF_RGB_FORMAT_ABGR, and are then converted to the requested type when the caller asked for something else.

Of the ImageReadParam settings, the source region, the source sub sampling factors and the destination are honoured. Band selection and the sub sampling offsets are not; the reader produces all four channels and starts every sub sampling block at its own top left corner.

See AvifCodec for how the native library is located. When it is missing, this reader still accepts its input, but any request that needs libavif fails with an IIOException that spells out what went wrong.

Instances are stateful and, as mandated by ImageReader, not thread safe.
