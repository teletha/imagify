AvifImageReader

  • ImageReader
ImageReader for AVIF images, backed by libavif.

An AVIF file holds either a single still image or an image sequence, and this reader reports whichever it finds: #getNumImages(boolean) answers 1 for a still and the frame count for an animation, and #read(int, ImageReadParam) decodes the frame asked for. The pixels arrive as a BufferedImage#TYPE_4BYTE_ABGR image, whose banks are the very A, B, G, R layout libavif fills in for AVIF_RGB_FORMAT_ABGR, and are then converted to the requested type when the caller asked for something else.

How long each frame is shown, and how often the sequence repeats, are reported through #getImageMetadata(int) and #getStreamMetadata() rather than through the standard metadata format, which has no notion of animation.

Of the ImageReadParam settings, the source region, the source sub sampling factors and the destination are honoured, by StillImageRead rather than here. Band selection and the sub sampling offsets are not; the reader produces all four channels and starts every sub sampling block at its own top left corner.

See AvifCodec for how the native library is located. When it is missing, this reader still accepts its input, but any request that needs libavif fails with an IIOException that spells out what went wrong.

Instances are stateful and, as mandated by ImageReader, not thread safe.

The index of the first frame, which for a still image is the only one.
