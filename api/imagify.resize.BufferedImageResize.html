imagify.resize

BufferedImageResize

High-quality BufferedImage resizing utility. Supports resampling algorithms: BILINEAR, CATROM, MITCHELL, LANCZOS3, HQX (xBRZ).

Usage example: 


 BufferedImage resized = BufferedImageResize.resize(original, 800, 600, ResizeAlgorithm.LANCZOS3);

resize(BufferedImagesource, inttargetW, inttargetH, ResizeAlgorithmalgorithm)BufferedImage

BufferedImagesource

the source image (any BufferedImage type)
inttargetW

target width (must be positive)
inttargetH

target height (must be positive)
ResizeAlgorithmalgorithm

the resampling algorithm to use
BufferedImage

the resized image

Resizes the source image to the specified dimensions using the given algorithm.
