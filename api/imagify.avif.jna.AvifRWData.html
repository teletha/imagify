Writable byte buffer owned by libavif: avifRWData.

size is a C size_t, therefore it is declared as a Java long (64 bit) rather than as com.sun.jna.NativeLong: size_t is 64 bit wide on every 64 bit platform, including Windows, where C long is only 32 bit wide.
