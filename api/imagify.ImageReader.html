ImageReader

Reads BufferedImage from various sources with automatic format detection.

Supported sources: byte[], Path, InputStream.

Format detection priority:

  1. Explicit ImageFormat parameter
  2. File extension
  3. Magic byte header

Usage:


 BufferedImage img = ImageReader.read(path);
 BufferedImage img = ImageReader.read(bytes, ImageFormat.PNG);
 BufferedImage img = ImageReader.read(inputStream);
