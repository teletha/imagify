ImageReader

Reads images from various sources with automatic format detection.

Supported sources: byte[], Path, InputStream.

Format detection priority:

  1. Explicit ImageFormat parameter
  2. File extension
  3. Magic byte header

Returns a FrameSequence which contains one or more frames. For single-image formats (JPEG, PNG, BMP), a single-frame sequence is returned. For animated formats (GIF, animated WebP), all frames and their delays are automatically extracted.

GIF delayTime is automatically converted from centiseconds to milliseconds.

Usage:


 FrameSequence seq = ImageReader.read(path);
 BufferedImage firstFrame = seq.toBufferedImage();
 List<BufferedImage> allFrames = seq.frames();
 int[] delays = seq.delaysMs();
