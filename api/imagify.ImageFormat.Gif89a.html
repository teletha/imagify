ImageFormat.Gif89a

  • ImageFormat

GIF89a, the animated and interlaced flavour of #GIF.

It is a constant of its own because the version number in the header is the only thing that tells the two apart, and a caller that read a file back may want to write it in the same flavour. Both answer "gif" to #getFormatName(), because they share a single encoder, so writing either one produces a plain GIF file.

getFormatName()String

String

The encoder is the GIF one, which is registered as "gif", not "gif89a".
