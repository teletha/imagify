Encoder state: avifEncoder.

libavif 1.1.0 appended headerFormat after csOptions and 1.2.0 appended qualityGainMap after that. Neither member is declared here; all members that are actually configured have identical offsets in every 1.x release.

codecChoiceint

An avifCodecChoice value.

maxThreadsint

Number of threads used for encoding.

speedint

Codec specific speed, 0 (slowest, best) to 10 (fastest, worst).

keyframeIntervalint

Distance between two key frames, in frames.

timescalelong

Timescale of the media in Hz; must be non zero.

repetitionCountint

Number of times an image sequence is repeated.

extraLayerCountint

Number of extra layers to encode; 0 for a plain still image.

qualityint

Overall quality, 0 (worst) to 100 (lossless), or AvifLibrary#AVIF_QUALITY_DEFAULT.

qualityAlphaint

Quality of the alpha plane, same range as #quality.
