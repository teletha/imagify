BufferedImageResize

High-quality BufferedImage resizing utility. Supports resampling algorithms: BILINEAR, CATROM, MITCHELL, LANCZOS3, HQX (xBRZ).

resize(inttargetW, inttargetH, ResizeAlgorithmalgorithm)FunctionBufferedImage, BufferedImage

inttargetW

the width to resize to
inttargetH

the height to resize to
ResizeAlgorithmalgorithm

the resampling algorithm
FunctionBufferedImage, BufferedImage

a function that produces the resized image

Returns a function that resizes an image to the given dimensions.

The target size and the algorithm are fixed when the function is built, so the same function can be applied to every frame of a FrameSequence without recomputing either. The source is normalised to BufferedImage#TYPE_INT_ARGB on the way in, which is the same normalisation BufferedImageTransform applies, so the result of one of these can be handed straight to the other.
