Registers WebpImageWriter with ImageIO.

Encoding needs the native libwebp library, which this jar bundles and unpacks on first use. To keep ImageIO usable when that library is absent, #canEncodeImage(RenderedImage) answers false in that case, which makes ImageIO.write() return false instead of failing hard.
