High-quality image resampling algorithms for resizing. Each algorithm provides a kernel function and a support radius.

NEARESTResizeAlgorithm

Nearest neighbour - preserves exact pixel values, essential for pixel art.

AREAResizeAlgorithm

Box / area averaging - ideal for downscaling, no ringing.

BILINEARResizeAlgorithm

Linear interpolation between the two nearest neighbours - the cheapest smooth filter.

BSPLINEResizeAlgorithm

Bicubic B-spline (B=1, C=0) - smoother than Catmull-Rom.

CATROMResizeAlgorithm

Catmull-Rom bicubic (B=0, C=0.5) - sharper than Mitchell, at the price of some ringing.

MITCHELLResizeAlgorithm

Mitchell-Netravali bicubic (B=C=1/3) - the softest of the cubics, and free of ringing.

GAUSSIANResizeAlgorithm

Gaussian blur kernel - smooth, no negative lobes.

LANCZOS2ResizeAlgorithm

Lanczos with a two-lobe window - a sinc truncated at two samples on each side.

LANCZOS3ResizeAlgorithm

Lanczos with a three-lobe window - the sharpest resampling filter here, and the ringiest.

HQXResizeAlgorithm

xBRZ, which is an edge-aware upscale rather than a convolution: it finds similar neighbours and blends them along their edge rather than averaging everything in reach. It is therefore the algorithm to pick for pixel art, where a blur is a defect rather than a smoothness. The kernel is unused, and the support is zero, because this one is not a convolution at all.

DEFAULTResizeAlgorithm

The default algorithm.

kernel(doublex)double

doublex

the distance from the sample point, in source pixels, absolute value
double

the weight to give that sample

The resampling weight at x samples from the pixel being looked at, where x is the distance already made positive. It is zero outside the support radius, so a resampler can walk the window without testing the bound itself.

Override this to add a filter; the algorithms that are not convolutions return zero because nothing ever calls them.

getSupport()int

int

the support radius in source pixels

How many source pixels on each side of a sample the kernel reaches, which is what decides how wide the resampling window has to be.
