One codec with a managed native library, which is everything the resolution below needs to know about a format:

format
the cache directory and the properties resource the release tag lives in
prefix
the release assets are named <prefix><platform>-<cpu>.<ext>, which is also the name the natives workflow gives the files it publishes, so a name in a bug report says which build it came from
property
the system properties of the codec all start with this, so -Dimagify.webp.library=/path/to.so names a library explicitly and -Dimagify.webp.bundled=false turns the managed library off
