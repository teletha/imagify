imagify.avif.ffm

AvifSequence

  • AutoCloseable

Walks the frames of an AVIF file, decoding them one at a time.

A file holds either one still image or a sequence, and this treats both the same way: a still is a sequence of one. #frameCount() is answered from the container headers alone, so asking how many frames there are never decodes a pixel, and #frame(int) decodes only the frame asked for.

The sequence holds a decoder that the shim allocated, so it is meant to be closed, ideally with try with resources: 


 try (AvifSequence sequence = AvifCodec.openSequence(bytes)) {
     for (int i = 0; i < sequence.frameCount(); i++) {
         BufferedImage frame = sequence.frame(i);
         // ...
     }
 }

Instances are not thread safe.

Decodes one frame as a BufferedImage#TYPE_4BYTE_ABGR image, whose banks are the very A, B, G, R layout the shim produces.

Frames come back at the size they are stored at, which for a sequence that updates only part of the canvas is smaller than #info(). The alpha channel is fully opaque when the file carries none.
