imagify.jpeg.ffm

JpegliLibrary

FFM binding for the C ABI in src/main/native/jpegli/imagify_jpegli.h.

This is the Foreign Function & Memory API (JEP 454) counterpart to the JNA binding that used to sit in imagify.jpeg.jna. It describes the function signatures of the jpegli based shared library and calls them through java.lang.foreign. There are no structures to describe: the shim keeps struct jpeg_compress_struct and struct jpeg_decompress_struct on its own side of the boundary and exposes only plain scalars, pointers and buffers, which is exactly what makes an FFM binding of it small.

See JpegliCodec for how the native library is loaded and called.

LIBRARY_NAMEString

Name of the shared library as this jar builds it.

Deliberately not jpeg. jpegli's own libjpeg62 compatible library is named libjpeg.so.62, which is also the name of every system libjpeg on Linux, and two of those can end up mapped in one process. This jar has no reason to interoperate with a system libjpeg, so the bundled library is given a name of its own.

ABI_VERSIONString

The version of the C ABI this binding was written against, as IMAGIFY_JPEGLI_ABI_VERSION in src/main/native/jpegli/imagify_jpegli.h spells it.

It is checked once when the library is loaded and nothing else depends on it, because the only way it could ever be wrong is a library built against a different revision of the header, and that has to be caught before the first call rather than after it has read a size from the wrong offset.

IMAGIFY_JPEG_SAMP_444int

IMAGIFY_JPEG_SAMP_422int

The colour channels half the width.

IMAGIFY_JPEG_SAMP_420int

The colour channels half in both directions, the smallest file.

IMAGIFY_JPEG_MIN_QUALITYint

The lowest quality the encoder accepts.

IMAGIFY_JPEG_MAX_QUALITYint

The highest quality the encoder accepts.

DEFAULT_QUALITYint

Quality the ImageIO writer and JpegWriteParam use when a caller does not ask for one.

The number is the one imagify.ImageFormat.Jpeg carries as its 0.0 to 1.0 defaultQuality, restated on the encoder's own 1 to 100 scale, the same way AvifConstants.DEFAULT_QUALITY and WebpLibrary.DEFAULT_QUALITY restate theirs. A codec cannot read a package private member of the format that describes it, so each one says what it does by default and the format's own value follows it.

MESSAGE_LENGTHint

Size of the buffer every entry point writes its failure description into.

Matches JMSG_LENGTH_MAX in jpeglib.h, which is what bounds the text libjpeg has formatted before it reports the error.

JpegliLibrary(SymbolLookuplookup)

SymbolLookuplookup

a symbol lookup that can resolve the imagify_jpegli_* symbols

Creates a new FFM binding for the native library identified by lookup.

The caller is responsible for ensuring the library is already loaded (via System#load(String) or System#loadLibrary(String)) so that its symbols are visible to the lookup it passes in.
