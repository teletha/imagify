FrameSequence

A sequence of image frames with their display durations.

Used for animated formats such as GIF, animated WebP, and animated AVIF. For single-image formats, this contains a single frame.

FrameSequence(ListBufferedImageframes, intdelaysMs, intloopCount)

ListBufferedImageframes

the frames, all of the same size, at least one
intdelaysMs

how long each frame is shown in milliseconds, one entry per frame
intloopCount

how many times the animation repeats, 0 meaning forever

Creates a frame sequence.

frames()ListBufferedImage

ListBufferedImage

the frames in display order, never null

The frames themselves, in the order they are meant to be played.

delaysMs()int

int

how long each frame is shown in milliseconds, one entry per frame

The timing, one entry per frame, held as a copy so that a caller editing what it gets back cannot desynchronise the sequence.

loopCount()int

int

how many times the animation repeats, 0 meaning forever

How many times the whole sequence repeats, in the sense the container formats use: zero means it plays for ever rather than never.

frameCount()int

int

the number of frames

The length of the sequence, which is always at least one because an empty one has nothing to describe.

toBufferedImage()BufferedImage

BufferedImage

the first frame

Returns the first frame as a BufferedImage.

Convenience method for when a single-image operation is needed, such as writing to a format that does not support animation.

firstFrameOnly()FrameSequence

FrameSequence

a single frame sequence

Returns a sequence holding only the first frame, dropping every other frame.

The delay and loop count of the first frame are kept. Returns this instance unchanged when it already holds a single frame.
