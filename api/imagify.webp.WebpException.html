WebpException

  • Exception
  • Throwable
  • Serializable

Signals that a WebP operation failed.

The most common causes are a missing or unloadable libwebp native library, which this jar fetches on first use, and malformed input.

WebpException(Stringmessage)

Stringmessage

the detail message

Creates an exception carrying only the detail message, for a failure libwebp reported in text and nothing else.

WebpException(Stringmessage, Throwablecause)

Stringmessage

the detail message
Throwablecause

the underlying failure

Creates an exception wrapping the failure it was given, for an error raised while fetching or loading the shared library rather than reported by it.
