The two ways this library reaches libwebp.

Each one knows whether it can be used in this JVM and why not, which is what the choice between them is made on.

FFMBackend

libwebp through Java's Foreign Function & Memory API, in imagify.webp.ffm. The default, and the one that can be told how hard to try.

WEBP4JBackend

libwebp through JNI and webp4j, in imagify.webp.webp4j. It needs no third party native access flag, and it cannot be told how hard to encode a still image.
