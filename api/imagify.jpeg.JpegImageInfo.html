JpegImageInfo

  • Record

Properties of the image contained in a JPEG file, as reported by its frame header.

A JPEG says all of this before a single pixel is decoded, so this is what a caller reads when it only wants to know how large a file is.

DENSITY_UNIT_ASPECT_RATIOint

The density is not a resolution but a ratio between the two axes.

DENSITY_UNIT_DOTS_PER_INCHint

The density is in dots per inch.

DENSITY_UNIT_DOTS_PER_CENTIMETREint

The density is in dots per centimetre.

horizontalDensityDpi()int

int #horizontalDensity() converted to dots per inch, or 0 when there is no density

Returns the density in dots per inch, which is what the pixelWidth/pixelHeight of an ImageIO standard metadata tree is measured in.

A file that names dots per centimetre is converted, and one that only names an aspect ratio answers 0, because the standard metadata format has no unit to put the ratio in. The JDK reader does the same, so a file read either way describes itself the same.

verticalDensityDpi()int

int #verticalDensity() converted to dots per inch, or 0 when there is no density

Returns the vertical density in dots per inch.
