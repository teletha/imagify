ImageWriter

Writes BufferedImage to various destinations with format control.

Supported destinations: byte[], Path, OutputStream.

Format is determined by explicit ImageFormat parameter or inferred from the destination path extension.

Usage:


 byte[] png = ImageWriter.toBytes(image, ImageFormat.PNG);
 ImageWriter.toFile(image, Path.of("out.png"));
 ImageWriter.toStream(image, ImageFormat.JPEG, outputStream);
