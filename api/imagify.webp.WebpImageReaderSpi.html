Registers WebpImageReader with ImageIO.

Decoding needs the native libwebp library, which this jar fetches on first use. To keep ImageIO usable when that library is absent, #canDecodeInput(Object) answers false in that case, which makes ImageIO.read() fall through to the other providers instead of failing hard.
