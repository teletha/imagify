JpegException

  • Exception
  • Throwable
  • Serializable

Signals that a JPEG operation failed.

The most common causes are a missing or incompatible jpegli native library and malformed input.

Every message this carries comes either from the C shim in src/main/native or from #JpegException(String, Throwable) wrapping whatever the loader reported while loading the shared library, so the text is a description rather than a stable identifier. Nothing should parse it.
