Registers JpegImageWriter with ImageIO.

Encoding needs the native jpegli library. Unlike a format this library owns outright, JPEG is one the JDK already writes: claiming it here without a working library would mean every ImageIO.write() of a JPEG failed, so #canEncodeImage(RenderedImage) answers false whenever the library is unavailable, which leaves the JDK's own writer to serve the image. That makes this provider a replacement rather than an addition, and a JPEG written through it comes out of jpegli rather than out of com.sun.imageio.
