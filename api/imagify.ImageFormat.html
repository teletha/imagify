Supported image formats with auto-detection capabilities.

Each format provides file extension, MIME type, magic byte headers, and whether alpha channel is supported.

Auto-detection can be performed via:

  • #fromExtension(String) - by file extension
  • #fromHeader(byte[]) - by magic byte header
  • #fromPath(Path) - by file extension + header fallback

JPEGImageFormat

JPEG format (.jpg, .jpeg). Lossy compression. No alpha support. Magic bytes: no reliable header (starts with 0xFF 0xD8).

PNGImageFormat

PNG format (.png). Lossless compression. Alpha support. Magic bytes: 0x89 0x50 0x4E 0x47 0x0D 0x0A 0x1A 0x0A

GIFImageFormat

GIF format (.gif). Lossless, indexed color. Alpha support (1-bit). Magic bytes: "GIF87a" or "GIF89a"

GIF89AImageFormat

WEBPImageFormat

WebP format (.webp). Lossy/lossless. Alpha support. Magic bytes: "RIFF...." + "WEBP"

AVIFImageFormat

AVIF format (.avif). AV1-based. Alpha support. Magic bytes: "ftyp" box with "avif" brand

BMPImageFormat

BMP format (.bmp). Uncompressed. Alpha support varies. Magic bytes: "BM"
