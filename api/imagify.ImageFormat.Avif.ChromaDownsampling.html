The filter the conversion from RGB reduces the colour-difference channels with, named the way the RGB image description enumeration writes it down.

This is a second, narrower thing than Subsampling: it decides how the reduction is done, not whether it happens. It therefore has nothing at all to do with a file stored as Subsampling#YUV444, where no channel is ever reduced.

AUTOMATICChromaDownsampling

The encoder chooses, which is the best balance of quality and speed.

FASTESTChromaDownsampling

The quickest reduction, which may show visible colour bleeding on saturated edges.

BEST_QUALITYChromaDownsampling

The best-looking reduction, which averages the chroma values.

AVERAGEChromaDownsampling

A simple box average of the chroma samples.

SHARP_YUVChromaDownsampling

A sharpness-preserving filter that tries to keep colour edges from smearing.

valueint
