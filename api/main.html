Imagify API Overview

This page provides a concise overview of the available APIs, including their purpose, key functionalities, and usage patterns. It serves as a starting point for developers to understand how to integrate and interact with the system effectively.

🛠️ Interface

AvifLibrary JNA binding for the subset of the libavif C API that is required to decode and encode AVIF images.
JpegliLibrary JNA binding for the C ABI in src/main/native/jpegli/imagify_jpegli.h.

AvifImage.ByReference View on an avifImage that is owned by somebody else, for example avifDecoder.image. JNA shares the parent's native memory, so the fields can be read and written directly once the parent structure has been read.
AvifROData Read only view on a block of bytes: avifROData.
AvifDiagnostics Error message buffer filled in by libavif: avifDiagnostics.
ImageWriter Writes images to various destinations with format control.
BufferedImageResize High-quality BufferedImage resizing utility. Supports resampling algorithms: BILINEAR, CATROM, MITCHELL, LANCZOS3, HQX (xBRZ).
SpriteSheet Creates sprite sheets from multiple image frames.
ImageFormat.Bmp BMP format (.bmp). Uncompressed. Alpha support varies. Magic bytes: "BM"
ImageFormat.Avif AVIF format (.avif). AV1-based. Alpha support. Magic bytes: "ftyp" box with "avif" brand
ImageFormat.Webp WebP format (.webp). Lossy/lossless. Alpha support. Magic bytes: "RIFF...." + "WEBP"
ImageFormat.Gif GIF format (.gif). Lossless, indexed color. Alpha support (1-bit). Magic bytes: "GIF8", the four bytes every revision of the header begins with.
ImageFormat.Png PNG format (.png). Lossless compression. Alpha support. Magic bytes: 0x89 0x50 0x4E 0x47 0x0D 0x0A 0x1A 0x0A
ImageFormat.Jpeg JPEG format (.jpg, .jpeg). Lossy compression. No alpha support. Magic bytes: no reliable header (starts with 0xFF 0xD8).

StillImageRead Applies a ImageReadParam to an image that has already been decoded.
ImageResizer High-quality BufferedImage resizing utility.
BufferedImageTransform Pixel rearrangement operations on a single BufferedImage: cropping, rotating and flipping.

🛠️ Enum

SpriteSheet.Fit How a frame is made to fit its cell. The names follow the resizing methods of Imagify.
ImageFormat.Avif.ChromaDownsampling The filter the conversion from RGB reduces the colour-difference channels with, named the way the RGB image description enumeration writes it down.
ImageFormat.Avif.Subsampling How finely the colour-difference channels are stored, named the way the format's own pixel format enumeration writes it down.
ImageFormat.Jpeg.Subsampling How finely a JPEG stores its two colour-difference channels, named the way the format's own sampling factors are usually written down.
ResizeAlgorithm High-quality image resampling algorithms for resizing. Each algorithm provides a kernel function and a support radius.
