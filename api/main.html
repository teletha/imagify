Imagify API Overview

This page provides a concise overview of the available APIs, including their purpose, key functionalities, and usage patterns. It serves as a starting point for developers to understand how to integrate and interact with the system effectively.

🛠️ Interface

AvifLibrary JNA binding for the subset of the libavif C API that is required to decode and encode AVIF images.

🛠️ Class

AvifImageReaderSpi Registers AvifImageReader with ImageIO.
AvifImageWriterSpi Registers AvifImageWriter with ImageIO.
AvifImageWriter ImageWriter
AvifImageReader ImageReader
AvifIOStats I/O statistics collected while decoding or encoding: avifIOStats.
AvifRGBImage A block of interleaved RGB(A) pixels handed to, or received from, libavif: avifRGBImage.
AvifEncoder Encoder state: avifEncoder.
AvifEncoder.ScalingMode avifScalingMode
AvifEncoder.Fraction avifFraction
AvifDecoder Decoder state: avifDecoder.
AvifDecoder.AvifIO Opaque handle for avifIO; its layout is private to libavif.
AvifImageTiming Timing information of a single frame of an image sequence: avifImageTiming.
AvifRWData Writable byte buffer owned by libavif: avifRWData.
AvifCodec Entry point to the libavif based AVIF codec.
AvifImage A decoded or to be encoded AVIF image: avifImage.
AvifImage.CleanApertureBox avifCleanApertureBox
AvifImage.PixelAspectRatioBox avifPixelAspectRatioBox
AvifImage.ContentLightLevelInformationBox avifContentLightLevelInformationBox
AvifImage.ImageMirror avifImageMirror
AvifImage.ImageRotation avifImageRotation
AvifImage.ByReference View on an avifImage that is owned by somebody else, for example avifDecoder.image. JNA shares the parent's native memory, so the fields can be read and written directly once the parent structure has been read.
AvifROData Read only view on a block of bytes: avifROData.
AvifDiagnostics Error message buffer filled in by libavif: avifDiagnostics.
