imagify.avif.jna

AvifLibrary

  • com.sun.jna.Library

JNA binding for the subset of the libavif C API that is required to decode and encode AVIF images.

The binding is modelled on include/avif/avif.h of libavif 1.x. Because libavif only ever appends new members to the end of its public structures, the layouts declared in this package are binary compatible with every libavif release from 1.0.0 up to and including 1.4.x. Fields that were added after 1.1.0 are simply not exposed.

The native library is not loaded by this interface; see AvifCodec for the lazy, failure tolerant loader.

AVIF_RGB_FORMAT_ABGRint

The in-memory layout of a java.awt.image.BufferedImage#TYPE_4BYTE_ABGR raster.

That raster declares band offsets of 3, 2, 1, 0, so the byte at offset 0 of a pixel is its alpha and the byte at offset 3 is its red. Passing the raster to libavif under #AVIF_RGB_FORMAT_RGBA therefore swaps red and blue in both directions without ever failing; see AbgrPixels.
