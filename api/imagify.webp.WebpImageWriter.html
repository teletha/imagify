WebpImageWriter

  • ImageWriter
  • ImageTranscoder
ImageWriter that encodes images as WebP using a bundled libwebp.

Any non empty RenderedImage can be encoded. The quality comes from the compression quality of the ImageWriteParam, whose 0.0 to 1.0 range is mapped onto the 0 to 100 range that libwebp expects. Lossless VP8L is selected by choosing the WebpImageWriterSpi#COMPRESSION_TYPE_LOSSLESS compression type, in which case the quality is ignored, exactly as libwebp ignores it.

Instances are stateful and, as mandated by ImageWriter, not thread safe.
